# Foresight Forcing project page

Static project page for **Foresight Forcing: Learning Spatial Foresight for Robotic Manipulation**.

## Local preview

Run from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Release checklist

- Replace the forthcoming paper and code controls in `index.html` with public links.
- Replace the anonymous BibTeX entry with the final arXiv metadata.
- Add author names and affiliations below the subtitle.
- Put optimized MP4/WebM files in `assets/videos/` and replace the real-world media status with the rollout gallery.
- Keep benchmark values synchronized with the released paper.

## GitHub Pages

The included workflow publishes this directory as a static GitHub Pages site. In the repository settings, set **Pages > Source** to **GitHub Actions**.
